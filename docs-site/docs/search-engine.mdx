# SearchEngine

Search Facebook for profiles, posts, groups, Marketplace listings, and Ad Library advertisements.

SearchEngine can be created with:

<code className="signature">SearchEngine(context: <Link to="/facebook-context">FacebookContext</Link>) -> <Link to="/search-engine">SearchEngine</Link></code>

SearchEngine has three search services:

<Props>
  <Prop name="general" type={<a href="#general-search">GeneralSearch</a>}>Profiles, posts, and groups.</Prop>
  <Prop name="marketplace" type={<a href="#marketplace-search">MarketplaceSearch</a>}>Marketplace listings.</Prop>
  <Prop name="ad_library" type={<a href="#ad-library-search">AdLibrarySearch</a>}>Meta Ad Library advertisements.</Prop>
</Props>

## General search

### general.search

<Props>
  <Prop
    name="general.search(text, filter_type='all', exact_match=False)"
    type={
      <>
        <Link to="/models/profile">Profile</Link>
        {' | '}
        <Link to="/models/post">Post</Link>
        {' | '}
        <Link to="/models/media-post">MediaPost</Link>
        {' | '}
        <Link to="/models/group">Group</Link>
      </>
    }
    iterator
  >
    Search for profiles, posts, or groups.
  </Prop>
</Props>

<Props>
  <Prop name="filter_type" type="str"><code>"all"</code>, <code>"profile"</code>, <code>"page"</code>, <code>"post"</code>, or <code>"group"</code>. <br /> (<code>"profile"</code> returns personal profiles. <code>"page"</code> returns only profiles that are Facebook Pages. Both yield <code>Profile</code> objects. <br /> <code>"all"</code> yields a mix of <code>Profile</code>, <code>Post</code>, <code>MediaPost</code>, and <code>Group</code>).</Prop>
  <Prop name="exact_match" type="bool"><code>True</code> requires an exact match. Defaults to <code>False</code> (fuzzy matching).</Prop>
</Props>

## Marketplace search

### marketplace.search

<Props>
  <Prop
    name="marketplace.search(query, *, ...)"
    type={<Link to="/models/marketplace-listing">MarketplaceListing</Link>}
    iterator
  >
    Search Marketplace listings.
  </Prop>
</Props>

<Props>
  <Prop name="is_stock_available" type="bool">Restrict to in-stock items. Defaults to <code>True</code>.</Prop>
  <Prop name="filter_location_latitude" type="float">Latitude of the search center. Defaults to <code>40.7128</code>.</Prop>
  <Prop name="filter_location_longitude" type="float">Longitude of the search center. Defaults to <code>-74.0060</code>.</Prop>
  <Prop name="filter_price_lower_bound" type="int">Minimum price. Defaults to <code>0</code>.</Prop>
  <Prop name="filter_price_upper_bound" type="int">Maximum price. Defaults to <code>2147483647</code>.</Prop>
  <Prop name="filter_radius_km" type="int">Search radius in kilometers. Defaults to <code>500</code>.</Prop>
  <Prop name="item_condition" type="str | None">Item condition: <code>"new"</code>, <code>"used_like_new"</code>, <code>"used_good"</code>, or <code>"used_fair"</code>.</Prop>
  <Prop name="last_n_days" type="int | None">Only include listings posted within the last N days.</Prop>
  <Prop name="sort_by" type="str | None">Sort order: <code>"CREATION_TIME_DESCEND"</code>, <code>"PRICE_DESCEND"</code>, <code>"PRICE_ASCEND"</code>, or <code>"DISTANCE_ASCEND"</code>.</Prop>
</Props>

## Ad Library search

Search the Meta Ad Library. Both methods below accept the same filters.

### ad_library.search

<Props>
  <Prop
    name="ad_library.search(query, *, ...)"
    type={<Link to="/models/advertisement">Advertisement</Link>}
    iterator
  >
    Search Ad Library advertisements.
  </Prop>
</Props>

### ad_library.count

<Props>
  <Prop name="ad_library.count(query='', *, ...)" type="int | None">
    Number of advertisements matching the filters, without fetching the ads themselves. Sends a request to Facebook. The value is reported by Facebook and may be approximate. Returns <code>None</code> if no count is available.
  </Prop>
</Props>

### Filters

<Props>
  <Prop name="query" type="str">Search text. For <code>count</code>, an empty string matches all ads allowed by the other filters.</Prop>
  <Prop name="filter_page_id" type="str">Restrict to a Facebook Page ID. Defaults to <code>"0"</code> (all Pages).</Prop>
  <Prop name="filter_active_status" type="str"><code>"ALL"</code>, <code>"ACTIVE"</code>, or <code>"INACTIVE"</code>. Defaults to <code>"ALL"</code>.</Prop>
  <Prop name="filter_country" type="str">Country ISO code, e.g. <code>"US"</code>. Defaults to <code>"ALL"</code> (all countries).</Prop>
  <Prop name="from_date" type="str | None">Start of the date range, <code>YYYY-MM-DD</code>.</Prop>
  <Prop name="to_date" type="str | None">End of the date range, <code>YYYY-MM-DD</code>.</Prop>
</Props>

## Example

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

engine = fgs.SearchEngine(context)

# General
for profile in engine.general.search("Ishowspeed", filter_type="profile", exact_match=True):
    print(profile.id, profile.display_name)

# Marketplace
for listing in engine.marketplace.search("iphone", filter_price_upper_bound=500):
    print(listing.id, listing.title, listing.price)

# Ad Library
total = engine.ad_library.count("Nike", filter_country="US", filter_active_status="ACTIVE")
print(total)

for ad in engine.ad_library.search("Nike", filter_country="US", filter_active_status="ACTIVE"):
    print(ad.id, ad.is_active, ad.advertiser.display_name)
    break
```
