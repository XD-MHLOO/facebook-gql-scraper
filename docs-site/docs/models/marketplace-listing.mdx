# MarketplaceListing

A Facebook Marketplace listing.

MarketplaceListing can be created with:

<code className="signature">MarketplaceListing.from_listing_id(context: <Link to="/facebook-context">FacebookContext</Link>, listing_id: str) -> <Link to="/models/marketplace-listing">MarketplaceListing</Link></code>

## Listing types

<Tabs>
<TabItem value="forsale" label="FOR_SALE_ITEM" default>

A regular Marketplace listing sold by a Facebook user.

</TabItem>
<TabItem value="partner" label="PARTNER_LISTING">

A partner listing, e.g. eBay. Has <code>partner_seller</code> and shipping metadata.

</TabItem>
</Tabs>

## Example

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

listing = fgs.MarketplaceListing.from_listing_id(context, listing_id="123456789876789")

print(listing.description)

for photo in listing.listing_photos or []:
    print(photo.image_url)
```
