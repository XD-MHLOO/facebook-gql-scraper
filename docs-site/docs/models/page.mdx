# Page

A Facebook Page. It's a public presence created by a business, brand, creator, organization or public figure.

Page can be created with:

<code className="signature">Page.from_page_id(context: <Link to="/facebook-context">FacebookContext</Link>, page_id: str) -> <Link to="/models/page">Page</Link></code>

## Properties

<Props>
  <Prop name="id" type="str">Facebook Page ID.</Prop>
  <Prop name="display_name" type="str | None">Display name of the Page.</Prop>
  <Prop name="url" type="str | None">Profile URL on the platform the Page is linked to.</Prop>
</Props>

## Methods

<Props>
  <Prop name="get_profile()" type="Profile" href="/models/profile">
    Attempts to return the Facebook <Link to="/models/profile">Profile</Link> linked to this Page. Only works when the Page's <code>url</code> is a Facebook URL.
  </Prop>
</Props>

:::note
A Facebook Page may be linked to an account on another platform (e.g. Instagram). get_profile() only supports Facebook profiles, so it raises ProfileNotAvailableException if the Page is linked to another platform.
:::

## Example

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

page = fgs.Page.from_page_id(context, page_id="103228679166389")
print(page.display_name, page.url)

# Get the linked personal Facebook profile
profile = page.get_profile()
print(profile.id, profile.display_name)
```
