# Advertisement

An advertisement from the Meta Ad Library.

Advertisement can be created with:

<code className="signature">Advertisement.from_ad_id(context: <Link to="/facebook-context">FacebookContext</Link>, ad_id: str) -> <Link to="/models/advertisement">Advertisement</Link></code>  

## Properties

**Identity & status**

<Props>
  <Prop name="id" type="str">Advertisement ID.</Prop>
  <Prop name="is_active" type="bool | None">Whether the ad is currently running.</Prop>
  <Prop name="categories" type="list[str] | None">Categories assigned to the ad.</Prop>
  <Prop name="start_date" type="int | None">Unix timestamp when the ad started running.</Prop>
  <Prop name="end_date" type="int | None">Unix timestamp when the ad stopped running. May be <code>None</code> for active ads.</Prop>
  <Prop name="publisher_platforms" type="list[str] | None">Platforms the ad runs on, e.g. <code>"FACEBOOK"</code>, <code>"INSTAGRAM"</code>.</Prop>
</Props>

**Content**

<Props>
  <Prop name="text" type="str | None">Body text of the ad.</Prop>
  <Prop name="snapshot" type={<><a href="#adsnapshot">AdSnapshot</a> | None</>}>Creative snapshot.</Prop>
  <Prop name="advertiser" type="Profile | None" href="/models/profile">Profile of the advertiser that published the ad.</Prop>
  <Prop name="fev_info" type={<><a href="#adfevinfo">AdFevInfo</a> | None</>}>Advertiser verification info.</Prop>
</Props>

:::note
The advertiser may not be a Facebook profile (e.g. an Instagram profile). It still returns a `Profile` (props like `display_name`, `url` and `profile_picture_url`) remain accessible. Accessing any other property raises [`NotFacebookProfileException`](/exceptions#not-a-facebook-profile), since only Facebook profiles can be resolved.
:::

</Props>

## Example

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

ad = fgs.Advertisement.from_ad_id(context, ad_id="1145379027885091")
print(ad.id, ad.is_active, ad.page.display_name)

snap = ad.snapshot
if snap:
    print(snap.page_categories, snap.display_format)
    for card in snap.cards or ():
        print(card.title)

# Ads that share the same creative
for similar_ad in ad.get_collation():
    print(similar_ad.id, similar_ad.page.display_name)
```
