# MediaPost

A Facebook media post — One [`Photo`](/models/photo) or [`Video`](/models/video) that is its own post, with its own comments and reactions.

MediaPost can be created with:

</TabItem>
</Tabs>

## Example

```python
import facebook_gql_scraper as fgs
from itertools import islice

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

# Fetch a media post directly by ID
mp = fgs.MediaPost.from_media_post_id(context, media_post_id="1109890145162796")
print(mp.id, mp.url)
m = mp.media
if isinstance(m, fgs.Photo):
    print(f"Photo: id={m.id} image_url={m.image_url}")
elif isinstance(m, fgs.Video):
    print(f"Video: id={m.id} video_url={m.video_url}")

for c in islice(mp.get_comments(), 10):
    print(c.text)

```
