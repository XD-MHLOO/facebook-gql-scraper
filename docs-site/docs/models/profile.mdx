# Profile

A Facebook user profile.

Profile can be created with:

<Tabs>
<TabItem value="id" label="From ID" default>

<code className="signature">Profile.from_user_id(context: <Link to="/facebook-context">FacebookContext</Link>, user_id: str) -> <Link to="/models/profile">Profile</Link></code>

</TabItem>
<TabItem value="username" label="From username">

<code className="signature">Profile.from_username(context: <Link to="/facebook-context">FacebookContext</Link>, username: str) -> <Link to="/models/profile">Profile</Link></code>

:::note
The username is resolved to an ID using regex matching. Prefer `from_user_id` when possible.
:::

</TabItem>
</Tabs>

## Example

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

user = fgs.Profile.from_user_id(context, user_id="100084254631043")
# Or from username: user = fgs.Profile.from_username(ctx, username="Ishowspeed")


for post in user.get_posts():
    print(post.id, post.text)
```
