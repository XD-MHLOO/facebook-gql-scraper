# Post

A Facebook post.

Post can be created with:

<Tabs>
<TabItem value="id" label="From ID" default>

<code className="signature">Post.from_post_id(context: <Link to="/facebook-context">FacebookContext</Link>, post_id: str) -> <Link to="/models/post">Post</Link></code>

</TabItem>
<TabItem value="pfbid" label="From PFBID">

<code className="signature">Post.from_pfbid(context: <Link to="/facebook-context">FacebookContext</Link>, pfbid: str) -> <Link to="/models/post">Post</Link></code>

:::note
The PFBID is resolved to an ID using regex matching. Prefer `from_post_id` when possible.
:::

</TabItem>
</Tabs>

## Example

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

post = fgs.Post.from_user_id(context, user_id="253053527513133")
# Or from PFBID: post = fgs.Post.from_pfbid(ctx, pfbid="pfbid0qHZRZohg13A1DmZpkFvHr3yuv7y1heFNnNoijtvi5onn1ctx2sjM5rRgTMSh6EGql")

for comment in post.get_comments():
    print(comment.id, comment.text)
```
