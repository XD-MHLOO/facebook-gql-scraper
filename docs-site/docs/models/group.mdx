# Group

A Facebook group.

Group can be created with:

<Tabs>
<TabItem value="id" label="From ID" default>

<code className="signature">Group.from_group_id(context: <Link to="/facebook-context">FacebookContext</Link>, group_id: str) -> <Link to="/models/group">Group</Link></code>

</TabItem>
<TabItem value="groupname" label="From groupname">

<code className="signature">Group.from_groupname(context: <Link to="/facebook-context">FacebookContext</Link>, groupname: str) -> <Link to="/models/group">Group</Link></code>

:::note
The groupname is resolved to an ID using regex matching. Prefer `from_group_id` when possible.
:::

</TabItem>
</Tabs>

## Example

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

group = fgs.Group.from_group_id(context, group_id="2781022932139267")
# Or from groupname: group = fgs.Group.from_groupname(ctx, groupname="workingmemes")

for member in group.get_members():
    print(member.join_status, member.contribution_score, member.profile.name)
```
