## Example

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

post = fgs.Post.from_post_id(context, post_id="253053527513133")

for comment in post.get_comments():
    print(comment.id, comment.text)
        
    for comment_reply in comment.get_replies():
        print(comment_reply.id, comment_reply.text)

        # (Facebook's max reply depth)
        for subreply in comment_reply.get_replies():
            print(subreply.id, subreply.text)
```

:::note
Facebook replies max depth is 2.
:::
