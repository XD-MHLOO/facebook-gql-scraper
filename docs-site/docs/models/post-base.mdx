# PostBase

The common base for [`Post`](/models/post) and [`MediaPost`](/models/media-post).

`PostBase` is never instantiated directly. It appears wherever the SDK returns an item that could be **either** a `Post` or a `MediaPost` — for example [`Profile.get_posts()`](/models/profile#methods) and [`Group.get_posts()`](/models/group#methods).

## Creating

<code className="signature">PostBase.from_any_id(context: <Link to="/facebook-context">FacebookContext</Link>, any_post_id: str) -> <Link to="/models/post">Post</Link> | <Link to="/models/media-post">MediaPost</Link></code>

:::note
Internally tries [`Post.from_post_id()`](/models/post) first, falls back to [`MediaPost.from_media_post_id()`](/models/media-post) on [`InvalidIdTypeError`](/exceptions#usage-errors) — cost up to **two** HTTP requests. If you already know the kind, call the specific factory directly.
:::

## Example

Resolve an id without knowing whether it is a post or a media post:

```python
import facebook_gql_scraper as fgs

context = fgs.FacebookContext(cookies_file="facebook_cookies.json")

item = fgs.PostBase.from_any_id(context, "1477518704237899")

if isinstance(item, fgs.MediaPost):
    print("media post:", item.id, item.media)
elif isinstance(item, fgs.Post):
    print("post:", item.id, item.text)
```
